# ICKIER_Furniture_Retailer_System
## SDP Group 2 - ICKIER Furniture Retailer System

ICKIER is a C# console-based online furniture retail system developed for our Software Design Patterns (SDP) assignment.

The system allows customers to browse and search furniture, customise selected products, add items to a shopping cart, checkout using different payment and delivery methods, manage orders, subscribe to brand promotions, and repeat previous orders.

### Design Patterns Implemented
- State
- Strategy
- Observer
- Decorator
- Factory Method
- Abstract Factory
- Command
- Composite
- Adapter
- Facade
